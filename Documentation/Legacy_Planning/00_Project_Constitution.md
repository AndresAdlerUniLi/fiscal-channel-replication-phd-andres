Project Constitution
The Fiscal Channel of Monetary Policy Replication Project
Version: 1.0
Project Status: Active
Institution: University of Liechtenstein
Research Area: Empirical Macroeconomics · Monetary Economics · Fiscal Policy · Financial Economics
1. Why This Project Exists
This project exists to build a transparent, reproducible, and institutionally rigorous replication of The Fiscal Channel of Monetary Policy while simultaneously developing the infrastructure required for independent empirical macroeconomic research.
The objective is not simply to reproduce published figures.
The objective is to understand every stage of the research process—from raw data collection to econometric estimation—so thoroughly that future research can be conducted without relying on opaque methodologies or undocumented assumptions.
This project is therefore both a paper replication and a long-term research platform.
2. What We Are Trying to Achieve
The project has four primary objectives.
First, faithfully replicate the original paper's empirical methodology and results using independently collected raw data and a fully reproducible workflow.
Second, document every decision made throughout the replication so that another researcher could independently reproduce the entire project without requiring verbal explanations or undocumented steps.
Third, construct a reusable macroeconomic data pipeline that can support future research beyond the original paper.
Fourth, develop the technical and methodological capability required to conduct original research in empirical macroeconomics, monetary economics, fiscal policy, financial stability, and macro-finance.
Replication is therefore viewed as the beginning of the research journey rather than its conclusion.
3. Guiding Principles
Every decision made throughout this project should satisfy the following principles.
Principle 1 — Reproducibility Above All
Every dataset, transformation, estimation, figure, and table should be reproducible from raw data.
If a result cannot be reproduced from scratch, it is considered incomplete.
Principle 2 — Data Before Econometrics
No model should be estimated until the underlying data are fully understood.
Variables must first be:
•	identified,
•	validated,
•	documented,
•	frequency-aligned,
•	and justified.
Good econometrics cannot compensate for poor data management.
Principle 3 — Documentation Is Part of the Research
Documentation is not an administrative task.
Documentation is part of the scientific method.
Every methodological decision should be recorded, including:
•	why it was made,
•	alternatives considered,
•	assumptions introduced,
•	expected consequences.
Principle 4 — Never Assume
Assumptions should never silently replace evidence.
Whenever uncertainty exists, it must be explicitly documented as one of:
•	Confirmed
•	Working Assumption
•	Open Question
The project should never confuse assumptions with established facts.
Principle 5 — Replication Before Innovation
No methodological improvements should be introduced until the original paper has first been faithfully replicated.
Extensions belong to a later phase.
Replication establishes credibility.
Innovation builds upon it.
Principle 6 — Simplicity Before Complexity
The simplest methodology capable of faithfully reproducing the published results should always be preferred.
Additional variables, nonlinear models, alternative estimators, or robustness analyses should only be introduced after the baseline specification has been validated.
Principle 7 — Transparency Over Convenience
Shortcuts that reduce transparency should be avoided even if they save time.
Manual work should eventually be replaced with reproducible code whenever practical.
Every transformation should be explainable.
Principle 8 — Every Dataset Tells an Economic Story
Variables are not merely columns of numbers.
Each dataset represents an observable component of the macroeconomy.
Understanding the economic interpretation of a variable is considered equally important as understanding its statistical properties.
4. Standards of Evidence
Every statement made during the project should belong to one of four categories.
Confirmed
Directly supported by:
•	the original paper,
•	official documentation,
•	or verified data.
Derived
Produced through documented transformations or econometric estimation.
Assumed
Necessary for workflow continuity but not yet verified.
Assumptions must always be clearly labeled.
Proposed
Ideas intended for future extensions rather than the current replication.
Replication and extension should never be confused.
5. Decision Framework
Whenever a methodological decision must be made, evaluate it using the following questions.
1.	Does it improve reproducibility?
2.	Does it remain faithful to the original paper?
3.	Is it economically justified?
4.	Can another researcher independently verify it?
5.	Does it reduce future ambiguity?
If the answer to most of these questions is "no," reconsider the decision.
6. Definition of Success
This project will not be considered successful merely because the published impulse response functions are approximately reproduced.
Success requires that another researcher be capable of:
•	rebuilding the dataset,
•	reproducing every transformation,
•	estimating the model,
•	generating every figure,
•	understanding every methodological decision,
•	extending the analysis,
without requiring additional explanation from the original author.
Reproducibility—not numerical coincidence—is the primary measure of success.
7. Relationship Between Replication and Extension
The project consists of two distinct phases.
Phase I — Replication
Objective:
Reproduce the published methodology and results as faithfully as possible.
No methodological innovation should occur during this phase unless absolutely necessary and explicitly documented.
Phase II — Extension
Only after the baseline replication has been completed should the project explore:
•	updated datasets,
•	longer sample periods,
•	alternative identification strategies,
•	Bayesian methods,
•	nonlinear specifications,
•	state-dependent responses,
•	geopolitical transmission,
•	financial stability implications,
•	or investor applications.
Extensions should always preserve a reproducible connection to the replicated baseline.
8. Long-Term Vision
This project is intended to become the foundation of a broader empirical macroeconomic research platform.
The infrastructure developed here should support future work in:
•	Monetary Economics
•	Fiscal Policy
•	Financial Stability
•	Macro-Finance
•	Geopolitical Economics
•	Central Banking
•	Sovereign Risk
•	International Capital Flows
•	Global Liquidity
•	Asset Pricing
Each future project should inherit the same standards of transparency, documentation, reproducibility, and methodological discipline established here.
9. Final Principle
Every dataset collected, every line of code written, every econometric model estimated, and every figure produced should move the project one step closer to a single objective:
To build research that is transparent enough to be trusted, rigorous enough to withstand academic scrutiny, reproducible enough to be independently verified, and valuable enough to serve as a foundation for future contributions to empirical macroeconomics.
